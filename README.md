# UPZ Signage — Landing Page V1

Static, mobile-responsive NYC commercial signage landing page. Uses UPZ Design's Montserrat typography and brand yellow/blue palette, informed by the supplied website source.

## Structure
- `index.html`: landing page
- `style/site.css`: isolated landing page styles
- `style/upz-original.css`: archived original UPZ Design stylesheet for reference; deliberately not loaded to avoid legacy selector conflicts
- `js/site.js`: mobile navigation and footer year

## Run
Open `index.html` in a browser or serve via a static server. Deploy via GitHub Pages (main / root).

## Before publishing
Replace photo placeholders with approved installation photographs; verify portfolio job scopes and permissions; connect an actual inquiry form (current CTA uses mailto); confirm service area and business contact details; add favicon and OG image. No tracking scripts or original production form credentials were copied.
